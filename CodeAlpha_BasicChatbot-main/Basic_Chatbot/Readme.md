## 📌 Project Overview
This project is an interactive, rule-based conversational agent developed in Python for the **CodeAlpha Python Programming Internship**. It parses user commands through string sanitization, matching patterns, and triggering contextual responses, live system time/date queries, and mini-games.

---

## 🚀 How to Run
```bash
python chatbot.py
```

---

## ✨ Features & Triggers
- **Greetings & Questions**: Responds to `hello`, `how are you`, `who are you`
- **Real-Time Data**: Responds to `time` and `date` with formatted system timestamps
- **Mini-Game**: Type `rock`, `paper`, or `scissors` to play against the bot
- **Fun & Inspiration**: Responds to `joke`, `quote`, `riddle`, and `fun fact`
- **Assistance**: Type `help` for command list
- **Exit**: Type `bye`, `exit`, or `quit` to end the session
